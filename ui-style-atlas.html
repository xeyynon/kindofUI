      On this page
      Install

      Run npm install brewkit in your project folder. Node 20 or later is required. The installer adds a brewkit.config.js file with sensible defaults, so most projects work straight away.

      Configure

      Open the config file and set your API key and region. Most teams only change the region and the output folder. Every option is listed in the reference, with its default value and an example.

      Deploy

      Run brewkit deploy to build and upload your site. The first deploy takes about a minute. Later deploys only upload files that changed, so they usually finish in a few seconds.

      Troubleshoot

      If a deploy fails, run brewkit doctor. It checks your Node version, API key and network, and prints the fix for each problem it finds.
