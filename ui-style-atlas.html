      On this page
      Install

      Run npm install brewkit in your project folder. Node 20 or later is required. The installer adds a brewkit.config.js file with sensible defaults, so most projects work straight away.

      Configure

      Open the config file and set your API key and region. Most teams only change the region and the output folder. Every option is listed in the reference, with its default value and an example.

      Deploy

      Run brewkit deploy to build and upload your site. The first deploy takes about a minute. Later deploys only upload files that changed, so they usually finish in a few seconds.

      Troubleshoot

      If a deploy fails, run brewkit doctor. It checks your Node version, API key and network, and prints the fix for each problem it finds.

        Delayed spinner (no flash of loading)

        Fast requests show no loader at all. A spinner appears only if the wait passes a short delay, and once shown it stays a minimum time, so quick loads never flash. Move the slider and press Refresh.

        Based on: NN/g on progress indicators (no looped animation under 1 second); the spin-delay library's defaults. The exact numbers are common practice, not research.

        Error summary on submit

        When a form fails, a box at the top lists every problem, each one a link to its field, and keyboard focus moves to it. Errors further down a long form are no longer missed, and screen reader users learn that submitting failed.

        Label placement

        Where a field's name lives. A placeholder disappears as soon as there is text, so filled and autofilled forms can't be checked. A floating label stays but is tiny. A label above the field is always readable. Switch between the three.
