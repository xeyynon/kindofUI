## Prompt for an AI assistant

Make my UI follow this accessibility and motion practice: Accessibility-first (WCAG).

What it is: Design so everyone can use it, including people with low vision, motor issues or screen readers: enough contrast, big targets, real labels and keyboard focus.
Good for: Every product, from the first sketch.
Watch out: Treating it as a final checklist item.
Seen in: GOV.UK, Apple, Microsoft Inclusive Design, legally required for many public sites

Steps:
1. Audit every page and component I share against this practice and list each problem with its element.
2. Fix the problems in code without changing the visual design more than needed.
3. Follow WCAG 2.2 AA and say which success criterion each fix covers.
4. Tell me how to test it myself: keyboard only, a screen reader, 200% zoom and reduced motion.

The kindofui example below shows the practice in a small working demo.

## Code

Copy and adapt. The HTML and CSS are scoped to this demo, so they will not touch the page they are pasted into.

```html

    <span class="hd b">✕ Hard to use</span><span class="hd g">✓ Accessible</span>
```
